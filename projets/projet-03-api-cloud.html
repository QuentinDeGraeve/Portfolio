Une API, de la conception au déploiement.

Un cas de référence pour détailler une API Spring Boot, sa sécurité, ses tests, son conteneur et son exploitation sur AWS.

Architecture de démonstration à réaliser
Le problème. Une API exploitable ne se limite pas à répondre à une requête : elle doit être testable, sécurisée, observable et déployable de manière reproductible.

Ce que la fiche détaillera. Découpage du code, validation, tests, conteneur, pipeline CI, Terraform et déploiement éventuel sur ECS Fargate. Le dépôt et l'environnement seront indiqués quand ils seront disponibles.
