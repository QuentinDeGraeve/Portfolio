# Mode Joueur vs Joueur (PvP)

## Description
Le mode joueur vs joueur permet à deux joueurs de combattre l'un contre l'autre sur le même clavier.

## Contrôles

### Joueur 1 (Adèle) - Côté gauche
- **Flèches directionnelles** : Se déplacer
  - Flèche gauche : Aller à gauche
  - Flèche droite : Aller à droite
  - Flèche haut : Sauter
  - Flèche bas : S'accroupir

- **Attaques**
  - **A** : Coup de poing (punch)
  - **Z** : Coup de pied (kick)
  - **E** : Attaque spéciale (cooldown: 3s)
  - **Q** : Dash (esquive rapide, cooldown: 1s)

### Joueur 2 (Héloïse) - Côté droit
- **Touches ZQSD** : Se déplacer
  - **Q** : Aller à gauche
  - **D** : Aller à droite
  - **Z** : Sauter
  - **S** : S'accroupir

- **Attaques**
  - **T** : Coup de poing (punch)
  - **Y** : Coup de pied (kick)
  - **U** : Attaque spéciale (cooldown: 3s)
  - **H** : Dash (esquive rapide, cooldown: 1s)

## Mécaniques de Jeu
- **Durée** : 90 secondes
- **Victoire** : Éliminer l'adversaire ou avoir plus de points de vie à la fin du temps imparti
- **Combo** : Les coups successifs augmentent les dégâts
- **Attaque spéciale** : Inflige plus de dégâts et a un cooldown plus long
- **Dash** : Permet de se déplacer rapidement pour esquiver les attaques
